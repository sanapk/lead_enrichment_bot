# 🤖 LeadGen AI Tool

Upload a list of company names → Get their website, industry, homepage analysis, and a pitch for AI automation!

## 🔧 Features

- ✅ Enrich company data using Clearbit
- 🌐 Scrape homepage text using BeautifulSoup
- 🤖 Use Gemini/OpenAI to summarize and suggest automation
- 📥 Download final CSV
- 🎛️ Bonus: Simple Streamlit UI

## 🚀 Setup

```bash
git clone https://github.com/your-username/leadgen-ai-tool
cd leadgen-ai-tool
